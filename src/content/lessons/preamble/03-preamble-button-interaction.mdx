Your page has a button, but a click currently changes nothing. Today you will give it one job: change a message beneath it. This is the smallest version of an app interaction.

**JavaScript** is code that can react to an action in the browser. The page needs a way to find the button and the message, so each can have an `id`, a short name used by the code.

Before editing, picture the result: the page begins with “Ready to start.” When you click the button, that message becomes “Thanks for clicking.”

Ask Codex for that one change:

```text
In my existing index.html page, make the button change a message
from “Ready to start.” to “Thanks for clicking.” when clicked.
Use plain JavaScript in the same file. Keep the existing page content.
Explain how the code finds the button and the message.
```

Open the file in the browser. You should see the first message before clicking and the second afterward. If the click does nothing, open the browser's **Console**—the panel where JavaScript errors appear—and share the exact error with Codex. You can also check that the names in the HTML and JavaScript match.

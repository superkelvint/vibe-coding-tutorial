Imagine writing a note and wanting to find both the note and an earlier version tomorrow. A project folder and Git solve those two needs. Today you will create a page file, open it, and save a checkpoint. The page will be plain text on a white background; styling comes next hour.

## Make a folder and a page

You need a browser, [VS Code](https://code.visualstudio.com/download), and [Git](https://git-scm.com/downloads). If either tool is already installed, keep using it. VS Code lets you edit files. A **terminal** is a window where you type commands. Git is the tool that records versions of files.

Create a folder named `tiny-page` and open it in VS Code. Add `index.html` with this content:

```html
<!doctype html>
<html lang="en">
  <head><meta charset="utf-8"><title>My first page</title></head>
  <body><h1>Hello from my page</h1></body>
</html>
```

The `.html` ending tells the browser this file describes a webpage. Open `index.html` in the browser. You should see “Hello from my page.” If you see the code itself, check that the file is named `index.html` and opened in the browser, rather than in a text preview.

## Save a version with Git

In the terminal inside the `tiny-page` folder, run:

```bash
git init
git add index.html
git commit -m "Add first page"
```

`git init` starts history for this folder. `git add` chooses the file to save. `git commit` records that version with a short description. If Git asks for your name and email, follow its message to set them, then rerun the commit. `git status` should say the working tree is clean when the file has been saved.

Change the heading to your own words and refresh the browser. You should see your new heading. `git status` should now show a changed file: your saved version still exists, and your newest edit has not been committed yet.

Think of a simple event page: it has a title, a short description, a few details, and a button. You will make that kind of page in the `index.html` file from Hour 1. The button will not do anything yet; Hour 3 gives it an action.

**HTML** names the things on a page. A heading is `<h1>`, a paragraph is `<p>`, a list uses `<ul>` and `<li>`, and a button is `<button>`. **CSS** tells the browser how to draw them, such as text size, spacing, and color.

Replace the content inside `<body>` with a heading, paragraph, three-item list, and button. You can ask Codex to help:

```text
In my index.html file, make a small event page with a heading,
a short paragraph, three details, and one button.
Add simple CSS in the same file so it is easy to read on a phone.
Explain which lines are HTML and which are CSS.
Do not make the button interactive yet.
```

Open or refresh the file in your browser. You should recognize the heading, paragraph, list, and button you asked for. Change one word and one color yourself, then refresh again. If nothing changes, check that you saved the file and refreshed the browser tab that opened this file.

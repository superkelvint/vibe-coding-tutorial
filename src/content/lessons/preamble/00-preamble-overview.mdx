You already use webpages. In the next four hours, you will make a tiny one and see what happens when someone clicks a button. You will also learn how to save a working version and how to ask Codex for one clear change.

| Hour | What you will see |
| --- | --- |
| 1. Files and Git | A page file in a folder and a saved project checkpoint. |
| 2. A tiny page | Your own words and styling in a browser. |
| 3. A click | A button changes something visible. |
| 4. Codex | A small requested change that you can open and inspect. |

A **browser** is the program that opens webpages. **Git** records versions of your project files. **Codex** can help change those files; you decide whether the result makes sense.

You will not need React, a server, a database, or a hosting account during these four hours. Those names will be introduced when the Chore Board needs them.

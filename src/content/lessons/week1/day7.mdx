You have a Chore Board that works on your laptop. Today is a pause to see the whole thing rather than add another technology. A person enters a chore; the browser sends a request; the server checks it; SQLite saves a row; the answer returns; the screen changes.

```text
person → React page → local server → SQLite file
                         ↓ answer ↓
                 React page shows the result
```

Open the app with the client and server commands from Day 6. Add a chore, mark it done, and refresh. The result should still be there. If it is missing, look first at the running server terminal and the browser Network panel. They will tell you whether the request was sent and answered.

Ask someone else to try adding and completing a chore on your laptop, if someone is available. Watch whether they understand the controls without a long explanation. Their hesitation is useful information; you do not need a formal interview or report.

## Leave a short handoff

Ask Codex to run the available project checks now that the local version is complete. Then write a few sentences for the next person: how to start the page and server, what the board can do, and that the data currently lives on this laptop. If the project has a README, put those sentences there. A **README** is the first project note someone usually opens.

```text
Inspect the current project and run its available checks.
Create or update a short README with the actual commands for starting
the page and server, what the Chore Board does, and where chores are saved.
Report any failed check briefly. Do not claim the app is online yet.
```

One person adds “Feed the dog” on the laptop. Another opens the Chore Board in a second browser and sees an empty list. The browsers each hold their own temporary copy. Today you will give both browsers one saved list to ask for.

A **server** is a program that receives a request and sends an answer. **SQLite** is a database program that keeps rows in a file on this laptop. A row is one saved chore. The browser will ask the server to load, add, or complete a chore; the server will read or change SQLite and answer. The browser will show waiting, success, or failure based on that answer.

The saved chore needs an id, title, assigned person, and done status. The id lets Done change the selected row instead of another chore with a similar name. A blank title must still be refused. You do not need to write SQL by hand; Codex can create the table and explain it.

## Connect the three parts

Keep the steps visible: first create the SQLite chores table, then make server requests for Load, Add, and Done, then connect the React board to those requests. Ask Codex to finish one step before starting the next.

```text
Make the existing React Family Chore Board use one local server and SQLite file.
Create a chores table matching the current title, assigned person, and done status.
Give the browser ways to load chores, add one, and mark one selected chore done.
The server checks blank titles and returns clear success or failure answers.
Work in three steps: database, server, then React connection.
Tell me how to start both programs and where to open the page.
When all three parts work together, run available project checks and
report pass or fail briefly.
```

The client and server may run in two terminal windows. Start each with the command Codex gives you, such as `npm run dev` for the page and `npm run server` for the local server. Open the URL printed by the page command. If chores do not load, check that the server terminal is still running. The browser Network panel shows whether the request got an answer; the server terminal shows errors from the server or database.

## Look at the result

Add a chore in one browser, refresh, and open the same local app in a second browser on the laptop. The saved chore should appear in both. Mark it done in one, then refresh the other; both should show Done. If they disagree, check whether both pages used the same server address and whether the server saved the row.

A family member asks, “Who is taking out the rubbish, and is it done?” Today you will make a page that answers that question while it is open. The page will let someone add a chore, choose a person, and mark one chore done. Refreshing will clear the list because there is no saved data yet.

This is the workflow you are building:

```text
name a chore → choose a person → add it → see it in the list → mark it done
```

One chore needs a title, an assigned person, and a done status. A blank title should not become a chore. Clicking Done on one row should leave the other rows alone. Those are the rules for this first version; there is no account, reminder, server, or database.

## Build one visible step at a time

Use a project folder for the Chore Board. Ask Codex to use plain HTML, CSS, and JavaScript. It should start with an empty board, then add the form, the list, and the Done action. Open the page after each step so you can see it take shape.

```text
Build a browser-only Family Chore Board in plain HTML, CSS, and JavaScript.
A person can enter a chore title, choose a family member, add the chore,
and mark exactly one chore done. Show a clear message for a blank title.
Keep chores in browser memory, so refresh clears the list.
Work in small visible steps and explain how to open the page.
At the end, run the project's available checks and tell me pass or fail briefly.
```

Codex may create a development command. A **development server** is a local program that serves the page while you work. If it does, run the command Codex gives you and open the local URL printed in the terminal. If it uses one HTML file, you can open that file directly in a browser.

## Look at the result

Add “Feed the dog” for one person and “Take out the rubbish” for another. Mark the first done. The first row should show Done, while the second remains unfinished. Refresh: the list should clear. If Add does nothing, look at the browser Console and tell Codex the exact error. If the wrong row changes, describe which row you clicked and which one changed.

The hosted board works. Now imagine changing its loading message. You want to see that change online before replacing the main version. A **Preview** is a temporary online version for that purpose. **Production** is the main version. **Configuration** means settings supplied to the app where it runs, such as the private database connection.

<img src={`${import.meta.env.BASE_URL}/images/week2-day13-environments.svg`} alt="Local, Preview, and Production run the app with settings supplied in each place; private database access remains on the server." />
<p class="image-caption">The code can be the same while each place supplies its own setting. The browser never receives the private value.</p>

| Place | Where the private setting belongs |
| --- | --- |
| Local laptop | An ignored `.env.local` file read by the server. |
| Vercel Preview | The project's private Preview environment setting. |
| Vercel Production | The project's private Production environment setting. |

Use the name `DATABASE_URL` in each place. The value may be the same for this fictional teaching project. If Preview and Production point to the same Supabase table, a chore added in Preview can also appear in Production. Check which table is in use before you change rows. Never put the connection value in a React file, a `VITE_` browser variable, a browser response, or a tracked file. Vercel's <a href="https://vercel.com/docs/environment-variables">environment settings guide</a> shows where these values are managed.

## Open a preview

Ask Codex to inspect the current project, confirm that only server code reads `DATABASE_URL`, and make one visible wording change, such as a clearer loading message. Use the project's existing preview deployment command, open the URL printed when it finishes, and look for the new wording. Open the main Production URL separately; it should keep its earlier wording until you intentionally deploy the change there.

```text
Inspect where DATABASE_URL is read. Do not show its value.
Make one small loading-message wording change, without adding a feature.
Tell me how to create a Vercel Preview for this project and where to find
its URL and build logs. Do not deploy to Production yet.
```

If Preview cannot load chores, check whether Preview has `DATABASE_URL` in Vercel's private settings. If the page itself will not load, read the preview build logs. If Production has the new wording already, verify which URL and deployment you opened. Do not change Production settings while diagnosing a Preview problem.

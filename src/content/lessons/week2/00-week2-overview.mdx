Your Chore Board works while the page, server, and SQLite file are on your laptop. Another person cannot depend on it when your laptop is closed. This week moves those jobs online one at a time. You will keep the same small chore workflow.

<img src={`${import.meta.env.BASE_URL}/images/week2-relocation-before-after.svg`} alt="Before, the page, server, and saved rows live on one laptop; after, the page and server run on Vercel and saved rows live in Supabase." />
<p class="image-caption">The page, server, and saved data move. Adding and completing a chore stays the same for the person using the app.</p>

| 13 | Which private setting does each version of the app use? |
| 14 | Can you explain and hand off the finished system? |

**Vercel** is a service that can put the page and server code at a public address. **Supabase** is a service that can host a Postgres database, a place for shared saved rows. Each name will be explained again when you need it.

The final result is a public URL where someone can open the Chore Board, add a fictional chore, refresh, and still see it. This is a teaching app. It does not include accounts or permissions for private family data.

You have moved the page, server code, and saved chores online. Today you will use the app from its main URL and tell another person how it works. The goal is a clear story, not another feature.

## Use the finished board

Open the Production URL in a fresh browser tab. Add one clearly fictional chore, assign it, and mark it done. Refresh; it should still be there. Open the same URL in another browser or on another device. That browser should see the same saved result. If it does not, compare the two URLs first. Then look at the first browser's Network request and the Vercel function logs. Check the Supabase row only if the server reported a save.

## Leave the next person a useful note

Ask Codex to inspect the actual project, run the available project checks, and update the README. It should state the real commands for starting the app locally, how the hosted parts connect, the production URL you actually opened, and known limits. It should never include a real connection value. Review the note before sharing it.

```text
Inspect the actual Chore Board project and run its available checks.
Update the README with the real local start commands, the public URL I
provide, where the page/server/database run, and known limits.
Do not invent a feature, test result, or URL. Do not include secret values.
Report pass or fail for the checks in one short paragraph.
```

This remains a teaching prototype. It uses fictional chores and does not provide accounts or private family permissions. A public URL is not evidence that private data would be safe here.

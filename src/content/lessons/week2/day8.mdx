Open the local Chore Board at an address such as `http://localhost:5173`. It works because a program on **your laptop** is running. If someone else opens that same address on their phone, `localhost` means **their phone**, not your laptop. That is why a public page must eventually ask a server that other browsers can reach.

A **URL** is an address for something a browser can request. The **host** part tells the browser which computer to contact. The **path** tells that computer which page or data is wanted. A **port**, such as `5173`, tells your laptop which running program should answer.

```text
http://localhost:5173/       → page program on this device
http://localhost:3000/api/chores → local server program on this device
https://example.com/         → a publicly reachable service
```

These example port numbers may differ in your project. Use the addresses printed by your running programs.

## Follow one local request

Start the Chore Board's page and server as on Day 6. Open the page and the browser's Network panel. Refresh. Find a request for chores and read its address. The browser should ask the local server, which answers with saved rows from SQLite. If the request fails, check the server terminal and the address the browser used.
